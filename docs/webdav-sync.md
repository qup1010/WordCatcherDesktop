# WebDAV 词库同步

插件和桌面端各自保存本地词库，通过同一个 WebDAV JSON 文件交换记录。浏览器到桌面端的本地 HTTP 桥接已删除，不再监听桥接端口，也不保留桥接设置或兼容接口。

```text
浏览器插件本地词库 ⇄ WebDAV 文件 ⇄ 桌面端 SQLite 词库
```

每个浏览器配置文件和桌面端都是独立客户端。多处「同步」按钮调用各自客户端的同一个同步服务，不额外建立数据副本。

## 配置与触发

- 各端使用相同的服务器地址和文件路径，默认路径为 `WordCatcher/vocabulary-sync.json`。
- 地址必须使用 HTTPS；HTTP 会同时暴露 Basic 认证凭据和词库内容，因此客户端拒绝连接。
- 插件在保存、编辑、删除、导入后触发防抖同步，打开单词本时也会尝试同步。
- 桌面端在启动、保存、编辑、删除、撤销删除、导入后触发防抖同步。
- 手动「立即同步」用于主动拉取其他设备的改动。当前没有定时轮询或服务端推送，不能保证持续实时更新。
- 自动同步需要启用 WebDAV 和自动同步开关。关闭后保留本地词库，手动同步入口仍可使用。

## 同步文件

同步文件采用 `format: word-catcher-learning`、`version: 3`、`records: []` 的结构。普通 JSON 导入与云端同步是不同操作：导入可以读取其他备份格式，云端合并只接受 v3 记录协议。缺少版本向量、重复 ID 或记录不完整都会停止同步，避免把残缺结果覆盖到云端。

| 字段 | 含义 |
| --- | --- |
| `id` | 不变的语境记录标识，允许 1–128 个 ASCII 字母、数字、连字符和下划线 |
| `revision` | 面向界面和诊断的正整数计数，不用于判断跨设备新旧 |
| `versionVector` | 每个设备对该记录的因果计数；本地保存、编辑、删除、恢复时只递增本设备分量，远端应用不会虚增分量 |
| `savedAt` / `updatedAt` | Unix 毫秒时间戳 |
| `deletedAt` | 删除标记，缺失表示有效记录 |
| `card` | 原始语境及释义快照，包含选区、原句、位置、来源和生成信息 |
| `edits` | 用户对释义、译文和备注的修改；空译文与缺失译文含义不同 |
| `wordMeta` | 可选的桌面词条摘要，不代替各条语境自己的释义 |

同步只按 `id` 定位，同一语境的不同 ID 保持独立；同一个 ID 不允许改指其他选区、原句、位置或来源。词条改名通过 `wordMeta.displayWord` 更新，本地未指定 ID 的重复收藏仍可以按语境查重。Anki 的语境标识继续沿用该记录 ID，不改成按单词合并。

同步文件不包含 API Key、WebDAV 密码，也不传播本机 Anki 的成功时间、错误或待同步任务。Anki 制卡是独立输出通道，不是词库同步的中转站。

## 冲突规则与写入保护

每次先下载、再合并、最后上传。版本向量明确表示一条编辑是否包含另一端已知的编辑：一端向量支配另一端时，支配方是后续版本；向量相等时内容必须相同；两向量并发且内容不同，或并发的删除与修改状态不同，会停止整批合并并保留两端数据。并发版本内容相同则按分量取最大值并上传合并后的向量。删除和恢复使用同一套因果判断，因此旧记录不能靠较大的本地修改次数复活。

桌面端在一个 SQLite 事务中预检并应用整批记录；任一记录失败时整批回滚。插件把有效记录与删除标记保存在同一个状态对象中一次写回。词条摘要仍按自身 `updatedAt` 选择较新内容；摘要时间戳相同但内容不同会停止同步。处理并发冲突时，可先分别导出两端备份，比较后在要保留的一端重新保存，再重新同步。

删除标记持续保存并参与上传，不按条数淘汰，避免长期离线的设备重新带回旧记录。恢复单条语境不会清除其他语境的删除标记。

上传已有文件必须使用下载时取得的强 ETag，发送 `If-Match`；创建不存在的文件使用 `If-None-Match: *`。服务器返回 `412` 时停止上传，下一次同步重新下载和合并。服务器缺少强 ETag 时拒绝覆盖已有文件，避免退回无条件覆盖。服务器还必须正确执行条件写入，单纯返回 ETag 不能替代这项能力。

## 当前边界

版本向量能识别记录级并发，但不做字段级自动合并，也没有冲突历史界面。用户需要先决定保留哪一侧，再在该侧重新保存并同步。桌面端通过数据库事务保护整批合并，且同步期间本地写入由仓储锁串行处理。

同步不是备份；普通词库备份只导出有效词条，不包含同步文件中的全部删除标记。真实服务商的条件写入兼容性需要在实际服务器上验证。

## 验证入口

两端测试使用内容相同的 `tests/Fixtures/webdav-v3.json`（桌面端）和 `tests/fixtures/webdav-v3.json`（插件）验证独立 ID、空译文、缺失备注、删除标记和重复往返。额外回归覆盖因果版本冲突、桌面批次回滚、并发条件写入、无 ETag 拒绝覆盖、异常文件保护以及长期保留删除标记。
