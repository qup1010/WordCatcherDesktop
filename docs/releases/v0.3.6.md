- 重构设置页为分组标签与 Fluent 卡片/折叠面板层级，补充 Mica 背景效果并统一查词窗口、词库与深浅主题视觉细节。

- 优化交互式启动流程与全局快捷键取词调度，补充 Windows 开机自启控制与安装路径修复。
- 改进 WebDAV 同步一致性、备份恢复与本地持久化可靠性。
