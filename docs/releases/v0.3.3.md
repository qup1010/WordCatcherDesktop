# Word Catcher 桌面版 v0.3.3

- 安装和卸载改由 Inno Setup 管理。首次安装可选择目录和桌面快捷方式；卸载保留 `%LOCALAPPDATA%\WordCatcher` 中的词库、设置和离线词典。
- 「设置 → 关于与更新」的手动检查会下载新版 Setup，点击「安装更新」后打开安装向导并默认沿用原安装目录。便携版仍通过下载新版 ZIP 手动更新。
- 统一单词快译与原句翻译的供应商和目标语言；AI 翻译由用户主动点击触发，快译失败时可改用 AI。

GitHub Release 提供 `WordCatcherDesktop-win-Setup.exe` 安装包和 `WordCatcherDesktop-win-Portable.zip` 便携包。安装包尚未配置代码签名。
