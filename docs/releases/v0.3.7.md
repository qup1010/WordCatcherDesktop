# Word Catcher 桌面版 v0.3.7

- 统一应用与托盘图标为 W 捕捉标记，并升级词头与音标字体为 `Segoe UI Variable`，支持浮窗长词自适应字号与防遮挡头部排版。
- 完善浮窗到主窗口的完整语境交接，自动保留未保存草稿、AI 详解与捕获来源，并精准定位已收藏语境记录。
- 改进生词库卡片复习流程：支持多选或当前筛选全量复习、完成总结与「需再练」标记闭环重练。
- 升级 WebDAV 同步冲突展示为逐字段高亮对比与相同字段折叠，明确覆盖方向操作。
- 增强在线快译稳定性：微软翻译支持 401 自动刷新 token 重试与并发原子读取，谷歌翻译超长文本自动切换 POST 表单。
- 保留桌面端升级安装时的既有安装目录设置。

GitHub Release 提供 `WordCatcherDesktop-win-Setup.exe` 安装包和 `WordCatcherDesktop-win-Portable.zip` 便携包。
