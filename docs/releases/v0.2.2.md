# Word Catcher 桌面版 v0.2.2

本次更新改善查词与生词整理体验，修复备份导出完整性问题，并加强跨应用取词保护。

## 更新内容

- 修复 JSON 导出最多 10,000 条词条的问题，超过该数量的词条与语境也会完整导出。
- 优先通过 UI Automation 读取选区；不支持时使用模拟复制，并加强剪贴板恢复、来源窗口检查与失败提示。
- 细化桌面主窗口、查词卡片、窗口按钮、导航选中状态与应用图标，改善文案和交互反馈。
- 整理项目目录，重写用户使用说明，补充浏览器插件介绍与新版展示图。

## 下载与使用

下载 `WordCatcher-v0.2.2-win-x64.zip`，完整解压后运行 `WordCatcher.App.exe`。支持 Windows 10 / 11 x64，无需另外安装 .NET。

## 验证范围

发布前完整自动回归 125 项通过，Windows x64 自包含构建通过。JSON 导出回归覆盖 10,005 条词条和 20,010 条语境。自动化检查不能替代真实应用验收：PDF、Word、浏览器中的完整取词场景，以及真实 Anki 的中断恢复、重试与模板保护验收仍待完成，详见仓库中的稳定性验证记录。
