# Word Catcher 桌面版 v0.3.9

- 新增截屏 OCR 取词（基于 WinRT OCR），支持识别后点击词片灵活选词并保留完整原句上下文收藏。
- 新增无障碍鼠标划词取词，支持进程黑名单与三种触发方式（显示查词浮标 / 检测到英语时自动翻译 / 划词后直接自动翻译）。
- 在线快译新增 B 站 Index-Translate 引擎并默认启用多引擎故障转移（微软 / 谷歌 / B 站自动切换），提升可用性。
- 新增中英自动互译，选中中文时自动翻译为英语（覆盖在线快译、整句翻译与 AI 详解）。
- 优化查词体验：未固定查词卡片一律支持点击外部或失焦关闭；将全局鼠标钩子迁至专用 Win32 消息线程并优化卡片阴影渲染以消除卡顿；修复多 DPI 弹窗定位与 AI 详解重复显示原文的问题。

GitHub Release 提供 `WordCatcherDesktop-win-Setup.exe` 安装包和 `WordCatcherDesktop-win-Portable.zip` 便携包。
