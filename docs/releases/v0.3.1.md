# Word Catcher 桌面版 v0.3.1

本次更新加入手动句子翻译，并改进翻译请求在窗口切换和设置变化时的可靠性。

## 更新内容

- 查词结果与词库语境支持手动翻译原句，翻译完成后可直接查看结果。
- 切换语境、记录或翻译设置后清理对应缓存；忽略过期请求，避免旧结果覆盖当前内容或重新写入缓存。
- 修复桌面端与浏览器插件中句子翻译交互的异步竞态和编辑内容覆盖问题。

## 下载与使用

下载 `WordCatcher-v0.3.1-win-x64.zip`，完整解压后运行 `WordCatcher.App.exe`。支持 Windows 10 / 11 x64，无需另外安装 .NET。

## 验证范围

发布工作流会运行完整自动测试并构建 Windows x64 自包含单文件压缩包；本版本包含桌面端手动句子翻译相关改动。
