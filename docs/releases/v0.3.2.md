# Word Catcher 桌面版 v0.3.2

- 启用每显示器 DPI 感知，改善笔记本高缩放和外接屏切换时的显示。
- 主窗口和查词浮窗按当前显示器工作区限制尺寸；窄窗口使用图标导航，调整词条列表和详情的比例。
- 优化查词输入框，使用连续细边框反馈焦点，移除绿色下划线。
- 提供当前用户安装器、自包含便携包，以及应用内更新所需的完整更新包和更新源。
- 安装器版本支持在「设置 → 关于与更新」手动检查并下载更新；下载完成后可点击重启安装。应用不进行后台自动检查，支持取消下载和重试。

首次使用安装器请下载 `WordCatcherDesktop-win-Setup.exe`。程序安装目录与现有词库数据目录独立，继续使用 `%LOCALAPPDATA%\WordCatcher` 中的词库和设置。

GitHub Release 同时提供 Setup 安装包和便携 ZIP。便携版用户下载新版便携包手动替换。当前安装包尚未配置代码签名。
