# Word Catcher v0.4.0

- 新增查词浮窗三种默认形态（极简译文 / 迷你卡片 / 完整卡片），补齐骨架屏加载与极简译文出错重试入口，并统一浮窗圆角与阴影层次。
- 升级鼠标划词浮标交互：支持悬停展开迷你卡片、右键菜单快捷操作，以及「不再在当前应用显示」一键加入禁用名单。
- 新增「查词」页离线词典前缀补全，支持键盘方向键选择、`Enter` 查词与 `Esc` 收起。
- 优化卡片复习体验：原句中自动高亮标记当前目标词（未能在句内定位时补充目标词提示），便于快速聚焦回忆。
- 新增语音朗读口音选择（美式 / 英式 / 跟随系统）与可选在线真人发音，离线或超时自动回退系统语音。
- 优化截屏 OCR 启动速度与小字识别预处理（窄小区域自动放大与背景留白，优先英文识别并自动回退系统语言）。
- 托盘右键菜单升级为原生风格弹出菜单；设置页新增关键词搜索过滤，并优化界面文案与文档展示。

GitHub Release 提供 `WordCatcherDesktop-win-Setup.exe` 安装包和 `WordCatcherDesktop-win-Portable.zip` 便携包。
