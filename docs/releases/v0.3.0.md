# Word Catcher 桌面版 v0.3.0

本次升级完善了本地词库复习、查词语境展示和 Anki 卡片，并优化了设置与主窗口交互。

## 更新内容

- 生词库新增卡片复习模式，以收藏时的原句和语境作为提示；可显示或隐藏答案，在卡片间切换、打乱顺序并朗读单词。
- 复习卡片展示语境释义、翻译、语境解析、用法提示、拓展例句和个人笔记；支持 `Space` 显示答案、方向键或 `J` / `K` 切换、`P` 朗读、`Esc` 退出。
- 词库详情补充来源链接和更清晰的语境字段；查词窗口分组呈现语境解析、用法提示和拓展例句，并在打开查词页时加载历史记录。
- 更新 Anki 的语境、识词、产词和听音卡片模板，展示词性、原句、翻译及可用的学习笔记；适配夜间主题。
- 设置页新增常见 AI 服务的地址与模型预设；改进主窗口最大化边界和设置开关悬停时的显示。
- 统一查词、保存和同步状态提示，并调整相关中文文案。

## 下载与使用

下载 `WordCatcher-v0.3.0-win-x64.zip`，完整解压后运行 `WordCatcher.App.exe`。支持 Windows 10 / 11 x64，无需另外安装 .NET。
