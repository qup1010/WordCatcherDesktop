# Word Catcher 桌面版 v0.2.3

本次补丁优化离线词典的词义顺序与卡片阅读体验，并与浏览器插件统一展示规则。

## 更新内容

- 普通词义排在姓名、专名之前，专名明确标注；同一词性内按核心、常用、少见义稳定排序。
- 摘要覆盖全部有效词性，每组最多 3 条不同释义，卡片摘要与保存内容使用一致的取值规则。
- 「完整释义」入口紧随摘要，详情按短释义、补充解释、例句和用法提示排列，避免重复解释。
- 默认展示一条例句，其余通过「更多例句」展开；原句与记忆线索保持次要层级。
- 同步更新使用说明，补充排序、摘要和例句回归测试。

## 下载与验证

下载 `WordCatcher-v0.2.3-win-x64.zip`，完整解压后运行 `WordCatcher.App.exe`。支持 Windows 10 / 11 x64，无需另外安装 .NET。

发布前 129 项自动测试通过，并检查了紧凑卡片、展开详情与桌面查词页的 WPF 实际渲染。PDF、Word、浏览器与 Anki 的完整真实场景验收仍未全部完成，详见稳定性验证记录。本次不包含内存占用优化。
