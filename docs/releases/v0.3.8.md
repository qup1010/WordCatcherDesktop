# Word Catcher 桌面版 v0.3.8

- 调整默认初始化配置为不启用 Anki 同步，未启用时托盘右键菜单自动隐藏「重试 Anki 待同步任务」。
- 修复 WebDAV 同步逻辑：仅在本地存在实际差异或未同步记录时上传，避免仅拉取远端更新时无谓回传。
- 为 WebDAV 写入增加 HTTP 412 有界自动重拉合并与 `PROPFIND` 强 ETag 一致性校验回退，提升并发与代理环境下的同步稳定性。
- 修复跨端词条空字段在桌面端导出与内容比对时被词级摘要回填覆盖的问题，避免同因果版本内容冲突。

GitHub Release 提供 `WordCatcherDesktop-win-Setup.exe` 安装包和 `WordCatcherDesktop-win-Portable.zip` 便携包。
