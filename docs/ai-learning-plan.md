# AI 语境学习实施与验收

两端使用 learning-v1 提示词与相同字段约定。选区、原句和位置是采集事实；expression 是 AI 识别的学习表达，不能替换选区。

已从两端当前源文件提取并对比提示词，中文正文逐字一致。

## 实施范围

- 按 word / phrase / sentence 分析，提供语境义、整句翻译和按需生成的关键解释、用法与例句。
- 两端流式展示，完整结果校验后才允许保存；取消请求同时停止生成；按提示词版本缓存，重新生成绕过缓存。
- 正式保存由用户触发。词条可以有多条语境，生成结果和用户编辑分别保存；同一语境更新必须明确点击更新。
- 扩展新增独立本地单词本与 JSON 导出，Anki 不在线时本地收藏保留。
- 桌面 SQLite 使用追加迁移保存语境快照，保留原始收藏、选区位置和同步任务。
- Anki 按语境身份创建或更新笔记，不再以单词首字段阻止不同语境。
- 较长解释保留在单词本，复习笔记只导出语境义、原句、译文和简短用法。

## 验收

- bank 不同原句的不同含义分别保存，同词新查询不覆盖收藏释义。
- stride 能识别 take something in stride，同时保留原始选区供高亮和挖空。
- 普通单词、短语、句子、没有原句、空字段、截断结果均覆盖。
- 流式过程中不能保存；切换、取消、重试、重新生成不串结果。
- 同语境重复保存不重复创建；明确更新保留用户编辑与原始生成内容。
- 用户编辑可在单词本中重开、导出；Anki 中不同语境不互相覆盖。
- SQLite 老版本迁移与两端完整回归通过，检查实际 UI 布局。

## 边界

旧数据库已被历史版本覆盖的释义无法恢复，迁移只能保留升级时仍存在的信息。旧扩展历史仅含摘要，不能伪造成完整学习记录；原有待同步卡片继续支持。

围绕原句追问和多轮讲解属于后续阶段，不包含在本次第一版。

## 当前验证记录（2026-10-07）

- 桌面端完整回归：Core 13、Infrastructure 38、App 86，共 137 项通过。随后收紧同语境草稿匹配条件，App 的 86 项再次通过。
- 扩展端：TypeScript 编译、24 个测试文件共 216 项测试、Chrome MV3 构建通过。
- 模拟接口覆盖语境快照、迁移、Anki 按语境创建与更新、SSE 流式、缓存与重新生成。扩展使用实际 AI SDK 运行模拟 SSE，验证空释义和长度截断拒绝，以及取消传到网络请求。
- 并发与编辑覆盖：新编辑不会被旧同步完成错误标为已同步；待同步队列保留同步过程中产生的新版本；删除一条语境不会删除同词其他语境。
- 扩展后台真实消息入口覆盖离线本地保存及入队、取消后迟到结果丢弃、正常缓存与主动重新生成、失败时不记录半成品。
- 两端 AnkiConnect 模拟协议覆盖同词不同语境创建不同笔记，同一语境更新已有笔记。未将模拟协议验证表述为真实 Anki 应用验证。
- 桌面弹窗及主查词页已渲染检查。浏览器侧栏用隔离示例数据检查历史还原、编辑、保存及单词本重开；网页浮层检查编辑、保存及重新生成后保留修改。示例检查不能证明真实接口或真实 Anki 应用的运行结果。
- 真实模型质量验收尚未完成：检查工具报告当前用户没有配置可用 AI API Key。测试通过不能代替对 bank、stride、普通词、短语、句子及无原句样例的实际输出检查。

真实模型检查使用现有设置及受保护凭据，不输出 API Key：

```powershell
dotnet run --project tools/AiLearningSmoke/AiLearningSmoke.csproj -c Release
```

扩展对 OpenAI 兼容服务在客户端执行结果校验；服务端是否支持严格 JSON Schema 取决于接口，不能把兼容模式视为服务端强制校验。
