**Word Catcher 桌面版** 是一款基于 WPF / Fluent UI 的 Windows 查词与生词整理应用，适用于 PDF 文献、Word 文档及各类桌面阅读软件。支持全局快捷键、鼠标划词与截屏 OCR 多种取词方式，结合离线词典、多引擎在线快译与 AI 语境详解快速理解词义，并将单词、原句和个人笔记留在本地，或通过 WebDAV 与 Anki 同步。

![Word Catcher 桌面版：跨应用查词与本地生词库](docs/images/showcase.png)

## 与浏览器插件配合

| 版本 | 适用场景 | 核心能力 |
| --- | --- | --- |
| **Windows 桌面版（本项目）** | PDF 文献、Word 文档与桌面应用 | 全局快捷键跨应用取词、本地 SQLite 生词库、卡片复习与多端同步 |
| [浏览器插件](https://github.com/qup1010/WordCatcher) | 外文文章、在线文档与网页浏览 | 网页划词浮窗、工具栏弹窗、侧边栏工作台与生词本复习 |

两端共享相同的词库数据模型与同步协议：配置相同的 HTTPS WebDAV 地址与文件路径后，收藏词条、原句、来源信息、个人编辑与删除记录会在两端合并同步；生词库 JSON 备份也可直接互相导入导出。应用设置、离线词典、查询历史和 Anki 同步任务各自独立保存在本机。详见 [WebDAV 同步说明](docs/webdav-sync.md)。

## 核心功能

### 1. 跨应用取词、鼠标划词与截屏 OCR

- **全局热键取词**：在任意支持文本选择的窗口中选中单词、短语或句子，按下全局快捷键（默认 `Ctrl+Shift+Z`，可在设置自定义）即可在光标附近弹出查词浮窗；应用内也提供「查词」页支持手动输入查询。
- **鼠标划词取词（可选）**：在「设置 → 常规与外观 → 划词与浮标」开启后，拖选或双击支持无障碍接口的文本即可无剪贴板干扰读取选区，支持配置进程黑名单及三种触发方式：
  - **显示查词浮标**：在光标旁显示迷你 `W` 浮标，点击后再查词。
  - **检测到英语时自动翻译**：划中英文跳过浮标直接弹出译文，中文等其他文本仍显示浮标。
  - **划词后直接自动翻译**：划词后直接弹出查词浮窗。
- **截屏 OCR 取词**：按下截屏快捷键（默认 `Ctrl+Shift+O`，可在设置自定义）框选屏幕区域，通过 Windows 原生 WinRT OCR 识别图片、扫描版 PDF 或视频字幕中的文字，识别后支持点击词片灵活选词并保留完整原句上下文收藏。
- **低侵入读取**：优先通过 UI Automation 直接读取选区文本；热键取词无法直接读取时自动备份当前剪贴板内容、模拟 `Ctrl+C` 取词并在完成后恢复原剪贴板（若期间用户新复制了内容则保留新内容）。
- **浮窗交互**：未固定浮窗点击外部空白处或失焦时自动关闭；点击图钉固定后可保持位置并刷新后续取词，支持系统语音朗读（TTS）、复制释义摘要、查看完整词典义项与记忆线索、切换「AI 详解」，以及一键「存入生词库」。

### 2. 三级查词引擎与中英互译

| 查词方式 | 内容与特性 | 使用说明 |
| --- | --- | --- |
| **离线词典** | 基于 [Open Dictionary](https://github.com/ahpxex/open-dictionary)（`distribution.sqlite.gz`），包含音标、词性分组释义、补充解释、记忆线索与例句 | 在「设置 → 查词与词典」一键下载或导入本地文件；命中后无需联网 |
| **在线快译** | 支持 **Microsoft 翻译**、**Google 翻译** 与 **B站 Index-Translate**，默认启用多引擎故障转移 | 未命中离线词典或输入整句时优先使用所选服务，不可用时自动切换至其他在线引擎 |
| **AI 详解** | 结合当前原句流式生成语境释义、整句翻译、核心表达与用法提示，支持重新生成 | 需配置兼容 OpenAI 格式的接口地址、模型名与 API Key |

- **中英自动互译**：默认开启；选中中文时自动翻译为英语（覆盖在线快译、整句翻译与 AI 详解），非中文内容仍输出目标语言。
- **词典展示策略**：离线词典将常规词性排在专名、人名之前，同一词性内按核心、常用、少见义排序；默认展示精简常用摘要，可随时展开查看完整义项与更多例句。
- **多 AI 方案与预设**：支持保存并切换多套 AI 配置，内置 `OpenAI`、`DeepSeek`、`Kimi`、`智谱 GLM`、`硅基流动` 与 `本地 Ollama` 预设及连通性测试。

### 3. 本地生词库与卡片复习

- **多语境积累**：每次查询自动记入最近历史，主动收藏后写入本地 SQLite 数据库；同一词条可关联多条不同来源窗口与原句语境，重新分析不会覆盖用户个人编辑。
- **检索与整理**：支持按单词、释义、备注、原句实时搜索；支持按状态（全部词条 / 待同步 / 同步失败 / 最近 7 天收藏 / 有备注 / 无备注）与来源应用过滤；支持排序（最近更新 / 单词 A–Z / 最近收藏）、紧凑列表、多选批量删除、详情内联编辑及删除后本次运行内撤销。
- **内置卡片复习**：在「生词库」中点击「卡片复习」进入自测模式，支持先看词条/原句、翻面显示释义、系统语音朗读及键盘快捷操作。

### 4. WebDAV 多端同步、备份与 Anki 联动

- **WebDAV 云端同步**：强制使用 HTTPS 连接，通过版本向量与强 ETag 条件写入保护云端数据，支持保存/编辑/删除/恢复后自动触发防抖同步与手动「立即同步」；若两端发生并发修改冲突，可在「同步状态」页逐字段对比并选择保留本地或云端版本。
- **Anki 联动制卡（可选）**：对接本机 [AnkiConnect](https://ankiweb.net/shared/info/2055492159)（默认 `http://127.0.0.1:8765`，默认牌组与笔记类型为 `Word Catcher`），支持目标词上下文挖空；Anki 未启动时自动入队并在「同步状态」页展示状态、错误详情与重试入口。
- **JSON 备份**：在「生词库」页支持导出与导入全部有效词条和语境的完整 JSON 备份（不受当前搜索或筛选影响），可直接与浏览器插件互通。

### 5. 原生外观、托盘常驻与升级管理

- **Fluent 视觉与适配**：支持浅色、深色与跟随系统主题及 Mica 窗口材质，支持 PerMonitorV2 多屏高 DPI 缩放；较窄窗口下左侧导航自动收折为图标栏。
- **分组设置与草稿保护**：设置页按「常规与外观」「查词与词典」「AI 详解」「同步与联动」「关于与更新」五个标签组织，切换标签自动保留未保存修改。
- **托盘与开机自启**：关闭主窗口时最小化到系统托盘，右键托盘菜单可完全退出；可在设置中开关 Windows 登录自启动，若安装目录发生变化还支持一键修复启动路径。
- **应用内更新**：安装版可在「设置 → 关于与更新」手动检查并下载 GitHub Release 安装包，启动安装向导时自动沿用当前安装目录覆盖升级。

## 安装与上手

运行环境要求：**Windows 10 / 11（64 位 x64）**。发布包为自包含构建，无需单独安装 .NET 运行时。

1. 前往 [GitHub Releases](https://github.com/qup1010/WordCatcherDesktop/releases) 下载对应版本：
   - **安装版（推荐）**：下载 `WordCatcherDesktop-win-Setup.exe`，支持自定义安装路径与桌面快捷方式（默认安装至 `%LOCALAPPDATA%\Programs\WordCatcherDesktop`，无需管理员权限）；后续升级自动沿用原安装路径并保留用户数据。
   - **便携版**：下载 `WordCatcherDesktop-win-Portable.zip`，解压至任意目录后运行 `WordCatcher.App.exe`。
2. 启动后程序常驻系统托盘，双击托盘图标即可打开主窗口。
3. 推荐首次使用顺序：在「设置 → 查词与词典」安装离线词典，在「设置 → AI 详解」配置模型接口（可选），随后在任意文档中选中英文单词并按 `Ctrl+Shift+Z` 即可体验。

更多安装、自启动、高 DPI 与升级机制说明见 [安装与升级说明](docs/installation-and-updates.md)。

## 本地数据与隐私边界

应用数据默认保存在 `%LocalAppData%\WordCatcher\`：

| 文件 / 目录 | 说明 |
| --- | --- |
| `wordcatcher.db` | 本地词条、语境快照、个人编辑、查询历史与 Anki 同步任务队列 |
| `settings.json` | 界面主题、快捷键、词典源、翻译与同步参数配置（保存时自动保留 `.bak` 备份） |
| `secrets.dat` | 使用当前 Windows 用户凭据通过 DPAPI 加密存储的 API Key 等密钥（含 `.bak` 备份） |
| `dictionary/` | 已安装的离线词典数据库 |
| `logs/` | 本地运行与错误排查日志 |

- **离线词典查词**：命中时完全在本地完成，不发起外部网络请求。
- **在线快译 / AI 详解**：仅在执行在线翻译或点击 AI 详解时，将待查文本（及 AI 所需的当前原句上下文）发送到你配置的服务地址；来源窗口标题与地址仅留在本地或写入你启用的 WebDAV 同步文件。
- **WebDAV / Anki / 更新检查**：WebDAV 强制 HTTPS，且不同步 API Key、WebDAV 密码及本地 Anki 队列；更新检查仅手动触发并访问 GitHub Releases。

## 常见问题

- **按下快捷键无反应或未取到文本**：确认快捷键未被其他软件占用，且取词时目标窗口仍保持前台；部分禁用文本复制的 PDF 阅读器、图片/扫描件或高权限管理员窗口可能会阻止读取或模拟复制，此时可改用截屏 OCR（`Ctrl+Shift+O`）或在主窗口「查词」页手动输入。
- **AI 连接测试通过但详解失败**：确认所选模型支持结构化 JSON 输出，且服务额度与模型名称填写正确；本地模型（如 Ollama）需先确认对应模型已拉取运行。
- **Anki 卡片停留在待同步**：确认 Anki 桌面版已启动且已安装插件代码 `2055492159`（[AnkiConnect](https://ankiweb.net/shared/info/2055492159)）并重启过 Anki，可在「同步状态」页展开「查看错误详情」后手动重试。
